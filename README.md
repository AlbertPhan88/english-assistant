# English Idiom Assistant

A personal Telegram bot that quizzes you on English idioms using spaced repetition (SM-2). Idioms are extracted from your PDF slides, paired with funny example sentences and Vietnamese equivalents, then delivered as fill-in-the-blank multiple-choice questions.

## Features

- Daily 6 AM quiz (10 idioms by default)
- `/quiz n` for on-demand quizzes
- SM-2 spaced repetition — weak idioms surface more often
- Funny example sentences generated by Claude
- Vietnamese equivalent idioms shown in answers
- `/stats` to track accuracy and weakest idioms

## Quick Setup (new machine)

### 1. Clone and install

```bash
git clone https://github.com/AlbertPhan88/english-assistant.git
cd english-assistant
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Create `.env`

```bash
cp .env.example .env
```

Edit `.env` and fill in:

```
TELEGRAM_BOT_TOKEN=       # from @BotFather on Telegram
ANTHROPIC_API_KEY=        # from console.anthropic.com
DAILY_HOUR=6              # local hour to send daily quiz
DAILY_IDIOM_COUNT=10      # questions per daily session
DB_PATH=data/idioms.db
TZ=Asia/Ho_Chi_Minh
```

### 3. Initialise the database

```bash
python -m src.main init
```

> Skip this if you cloned with the existing `data/idioms.db` — the DB is already populated with 933 idioms.

### 4. Run as a systemd service (auto-starts on reboot)

```bash
cp english-assistant.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now english-assistant
loginctl enable-linger $USER
```

The bot is now managed by systemd and will restart automatically on reboot or crash.

**Useful commands:**

```bash
systemctl --user status english-assistant     # check status
systemctl --user restart english-assistant    # restart after config change
systemctl --user stop english-assistant       # stop
journalctl --user -u english-assistant -f     # live logs
```

Send `/start` to your bot on Telegram to register, then `/quiz` to test.

### Run manually (dev/testing only)

```bash
python -m src.main run
```

## Re-ingesting slides (adding new PDFs)

Drop PDFs into `pdfs/` then:

```bash
python -m src.main ingest pdfs/your-file.pdf
python -m src.main fill-examples       # generate funny examples
python -m src.main fill-vietnamese     # generate Vietnamese equivalents
```

Already-ingested PDFs are tracked and skipped automatically on re-run.

### Sync from Google Drive

```bash
./setup_drive.sh           # one-time OAuth + download all session PDFs
python -m src.main ingest pdfs/*.pdf
python -m src.main fill-examples
python -m src.main fill-vietnamese
```

For `setup_drive.sh` to work you need `credentials.json` (Google OAuth Desktop app credentials) in the project root. See [Google Drive setup](#google-drive-setup) below.

## Google Drive setup

Only needed if you want to sync PDFs directly from Drive.

1. Go to [console.cloud.google.com](https://console.cloud.google.com)
2. Create a project → enable **Google Drive API**
3. **Credentials → Create → OAuth 2.0 Client ID → Desktop app** → download JSON
4. Save it as `credentials.json` in the project root
5. Add your Google account as a **Test user** under OAuth consent screen
6. Run `./setup_drive.sh` — it prints an auth URL, you open it, paste the code back

Token is saved to `data/token.pickle` and reused on future runs.

```
├── data/

└── src/
    ├── config.py         # env loading
    ├── db.py             # schema + helpers
    ├── extractor.py      # PDF → idioms via Claude
    ├── examples.py       # funny example + Vietnamese equiv generation
    ├── scheduler.py      # SM-2 algorithm
    ├── quiz.py           # question builder
    ├── bot.py            # Telegram bot + daily scheduler
    ├── drive.py          # Google Drive sync
    └── main.py           # CLI entrypoints
```
